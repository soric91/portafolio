# Capturas de proyectos

Guarda aquí las imágenes de cada proyecto y luego apunta el campo `img`
en `src/components/Proyectos.astro`, por ejemplo:

```
img: "/proyectos/monitoreo-energetico.webp",
```

Recomendaciones:

- Formato **.webp** (pesa menos) — también sirven .png / .jpg.
- Tamaño ideal **1200×675** (proporción 16:9, igual que el marco de la tarjeta).
- Nombres en minúsculas y con guiones: `bot-citas-whatsapp.webp`.

Mientras un proyecto no tenga imagen (`img: ""`), la tarjeta muestra un
relleno rayado con el texto "[ captura del sistema ]".
